# Test list: v0.5-slice5-webhook-server  (source: docs/design/v0.5-slice5-webhook-server.md)
Ordered as vertical slices — implement one before writing the next. Numbers in
parentheses reference the design's Testability items.

## Slice A — actionFromRequest (webhook/action.go)
1. [ ] A DELETE AdmissionRequest maps to `Verb: Delete` with the request's real GVK+ns+name+uid as the target (1).
2. [ ] `propagationPolicy: Orphan` maps to `Cascade:false`; Background/Foreground/absent map to `Cascade:true` (2, S4 #18).
3. [ ] An UPDATE request projects `oldObject`/`object` into `Action.Old/New` via `cluster.Project` (3a).
4. [ ] A `subResource: scale` UPDATE maps to `Verb: Scale` on the parent resource (4).
5. [ ] A pods/eviction CREATE maps to `Verb: Delete` on the pod — the eviction bypass is closed (5).
6. [ ] CONNECT and unknown operations return an error (6).
7. [ ] Unparsable payload JSON or a projection failure returns an error (7).

## Slice B — Handle core: taxonomy + modes (webhook/server.go)
8. [ ] An escaping delete is denied in enforce (`krsm:escape` + escaping refs) and allowed-with-warnings in audit (same refs + provenance `derived:ownership-tree`) (8).
9. [ ] An in-scope delete is admitted in both modes (9).
10. [ ] A non-agent request is admitted untouched; `AnnotationMatcher{Key:""}` matches everything (10).
11. [ ] A CREATE (non-eviction) is admitted before any state access — works even unsynced (11).
12. [ ] An unsynced cache denies with `krsm:not-ready` in BOTH modes (12).
13. [ ] A target absent from state stays a fail-closed Block through audit (13).
14. [ ] A selector-changing UPDATE reaches the old∪new match-set verdict through `Safe` (3b).
15. [ ] `request.uid` is echoed on every path including denies; `patch` is never set; no reason string leaks data (16).

## Slice C — staleness wiring (webhook/server.go + freshness seam)
16. [ ] A freshness-seam error denies with `krsm:stale` in both modes (14a).
17. [ ] After a successful freshness pass the recomputed decision is served (fake state whose second Safe differs) (14b).
18. [ ] A missing `oldObject.metadata.resourceVersion` denies with `krsm:stale` (15).

## Slice D — HTTP transport (webhook/http.go)
19. [ ] Non-POST → 405; wrong content-type → 415; undecodable body with no uid → 400 (17).
20. [ ] A handler panic yields 200 + `krsm:internal` deny (18).
21. [ ] A deadline expiring inside freshness denies rather than hanging (19).
22. [ ] `/readyz` is 503 before sync and 200 after; `/healthz` is always 200 (20).
23. [ ] certReloader serves the new certificate after the cert file changes (21).

## Slice E — cmd/krsm serve
24. [ ] `serve` refuses to start without `--tls-cert`/`--tls-key`; an invalid `--mode` is a usage error (22).

## Slice F — PR #32 review debt
25. [ ] `DiscoverTargets`: one Target per preferred GVR, Secrets/ConfigMaps enumerated as ordinary targets, C1-tolerant on an unrelated group failure (23).
26. [ ] The `state.New` wiring path splits full/metadata targets per `metadataKinds` (via the injectable seam) (24).
27. [ ] `PodsMatching` and `SelectorsMatchingLabels` parity rows: indexed Provider matches `NewScanState` directly on the corpus (25).
