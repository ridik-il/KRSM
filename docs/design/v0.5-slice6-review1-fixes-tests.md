# Test list: v0.5-slice6-review1-fixes  (source: docs/design/v0.5-slice6-review1-fixes.md)
Ordered as vertical slices. Implement each one before writing the next (red → green →
refactor). All webhook tests go through `Server.Handle` unless noted, and fail-closed
cases assert **both** audit and enforce mode.

## Step 1: a live contract clause inherits the contract's namespace
1. [x] A `prod` TaskContract CR whose resource clause omits `namespace` authorises that
   kind's objects in `prod`. A `Handle` request whose collateral is in `prod` is Allowed
   under L3.
2. [x] The same contract does **not** authorise the same-named object in `default`.
   Collateral in `default` escapes.
3. [x] A selector clause without a namespace behaves the same way (it gates `prod`).
4. [x] An offline YAML contract without `metadata.namespace` keeps the loader's `default`.
   Goldens 01–27 are unchanged (`TestScenarios`).

## Step 2: the L1 re-root is the target or an in-namespace owner ancestor
5. [x] Re-root at the target's owning Deployment still re-roots, with provenance
   `annotation` (existing `…TargetAnnotationReRoots` stays green).
6. [x] Re-root at the action target itself is accepted and gives the L0 verdict.
7. [x] Re-root at an unrelated object in the same namespace → deny `scope-unresolved` in
   both modes, with a message saying it is not an owner of the target.
8. [x] Re-root at a cluster-scoped object that owns the namespaced target → deny
   `scope-unresolved` (namespace rule).
9. [x] Re-root at an object in another namespace → deny `scope-unresolved` (namespace rule).
10. [x] An owner chain with an untracked intermediate (R owns X, X owns the target, X is
    not tracked) → deny `scope-unresolved`.
11. [x] An ownership cycle in state terminates and denies (no hang).

## Step 3: fail-fast serve validation (`runServe`, before any informer)
12. [x] `--target-annotation ""` and `--scope-annotation ""` are each rejected.
13. [x] A malformed key (e.g. `bad key/`, `-x`) is rejected.
14. [x] Target == scope, target == agent and scope == agent are each rejected. An empty
    agent annotation never collides.
15. [x] `--allow-namespace '*'`, `--allow-namespace 'a,,b'` and
    `--allow-cluster-scoped-kind '*'` are each rejected.
16. [x] Each rejection is returned by `runServe` before `serveWebhook`, with no cluster
    contact. Same pattern as `TestServeRejectsMalformedClusterScopedKind`, with dummy
    TLS paths and no kubeconfig.

## Step 4: re-key warning
17. [x] A non-default `--scope-annotation` logs exactly one warning naming the old and new
    key and "L0". Defaults log nothing.

## Step 5: test hygiene and the empty-`allow` contract
18. [x] An L3 contract with an empty `allow` denies the collateral in enforce and warns in
    audit (fail-safe, not an error). The comment is corrected to match.
19. [x] The `allowlistApplies` private-helper assertion is removed. Its end-to-end coverage,
    `TestAllowlistIgnoredForContractProvenanceEndToEnd`, stays.

## Gate
20. [x] `make check` is green (fmt, vet, golangci-lint, staticcheck, `go test -race`,
    archguard).
