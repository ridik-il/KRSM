# Design: v0.5-slice5-webhook-server
Status: draft · Date: 2026-07-11 · Slug: `v0.5-slice5-webhook-server` · Plan: docs/plans/v0.5-slice5-webhook-server.md

## Summary
A new `webhook/` package (outside the stdlib-only `closure`/`scope` trees, beside
`state/`) serving `ValidatingWebhook` AdmissionReviews over TLS. `Handle` is pure over a
decoded review plus injected collaborators (state, freshness seam, mode, matcher) and
runs the **unchanged** decision procedure: `actionFromRequest` →
`scope.Derive(target).Clauses` → `closure.Safe` → staleness guard → `scope.Mode.Apply` →
`AdmissionResponse`. Every uncertainty fails closed with one of five distinct,
credential-free reason codes. A `krsm serve` subcommand wires `state.New` →
`Start`/`WaitForCacheSync` → the TLS server with `/readyz` gated on sync. Level 1/3
scope, allowlist, and deployment manifests are slices 6–7.

## Interfaces / contracts

### `webhook/server.go`
```go
// Server evaluates AdmissionReviews against the indexed live state. Validating only:
// it never sets a patch. All collaborators are interfaces so Handle is hermetic.
type Server struct { /* unexported: state, fresh, scopeInfo, mode, matcher, logf */ }

// Config wires a Server. State/Fresh/ScopeInfo are satisfied by *state.Provider
// (Fresh via the freshness seam below); Synced gates serving (fail closed until true).
type Config struct {
    State     closure.State
    Fresh     freshness            // nil → staleness guard skipped (tests only; serve always sets it)
    ScopeInfo cluster.ScopeInfo    // for projecting request payloads via cluster.Project
    Synced    func() bool          // Provider.HasSynced
    Mode      scope.Mode           // validated: audit | enforce
    Matcher   AgentMatcher
    Logf      func(string, ...any) // nil → log.Printf
}
func New(c Config) (*Server, error)   // rejects invalid Mode / nil State / nil Synced

// Handle: decode-validated review in, response review out. Pure; ctx carries the
// per-request deadline (freshness GETs honour it). Never panics out (recover is
// ServeHTTP's job); never mutates the request; always echoes request.uid.
func (s *Server) Handle(ctx context.Context, review admissionv1.AdmissionReview) admissionv1.AdmissionReview
```

### `webhook/matcher.go`

### `webhook/action.go`
```go
// actionFromRequest maps an AdmissionRequest to the closure.Action, fail-closed:
// an unmappable request returns an error → deny(reasonInvalid).
func actionFromRequest(req *admissionv1.AdmissionRequest, scopeInfo cluster.ScopeInfo) (closure.Action, error)
```
Mapping (the request-fidelity contract):

| Request | Action | Note |
|---|---|---|
| `operation: DELETE` | `Verb: closure.Delete` | |
| `operation: UPDATE` | `Verb: closure.Update` | `Old`/`New` from payloads |
| `operation: UPDATE, subResource: "scale"` | `Verb: closure.Scale`, target = parent | `Old`/`New` nil (ScaleEffect needs neither) |
| `operation: CREATE, subResource: "eviction"` (pods) | `Verb: closure.Delete` on the pod | **eviction is a delete in disguise** — admitting it would be a gate bypass |
| `operation: CREATE` (else) | admitted before action-building | no existing closure; `closure.Verb` has no Create |
| `operation: CONNECT` or unknown | error → deny(reasonInvalid) | approved lean 3 |
| other sub-resources (`status`, `token`, …) | admitted | no relational effect |
| `options` → `DeleteOptions.propagationPolicy` | `Orphan → Cascade:false`; Background/Foreground/absent → `true` | **S4 #18** |
| `kind` + `name`/`namespace` + `oldObject.metadata.uid` | `Target closure.Ref` (real GVK + uid) | **S2 #16 webhook half** — no discovery guess |
| `oldObject` / `object` (RawExtension JSON → unstructured) | `Old` / `New` via `cluster.Project` | same projection as informers (parity); Project error → deny(reasonInvalid) |

### `cmd/krsm serve`
```
krsm serve --mode audit|enforce --listen :8443 --tls-cert FILE --tls-key FILE
           [--agent-annotation krsm.io/task] [--kubeconfig …] [--context …] [--resync 0]
```
Builds `state.New` → `Start` → `WaitForCacheSync` (fail: exit 1) → serve until
SIGINT/SIGTERM (reuses `runCheckLive`'s `signal.NotifyContext` idiom,
`cmd/krsm/main.go:270`). `--mode` defaults to **audit** (ADR-0011). Missing cert/key →
usage error (no plaintext fallback, ever).

## Data model

### Fail-closed taxonomy — the five reason codes
One helper builds every reason: `reason(code reasonCode, detail string) string` →
`"krsm:<code>: <detail>"` (approved lean 4; greppable by the slice-8 e2e). Codes:

| Code | Trigger | Audit-mode behaviour |
|---|---|---|
| `not-ready` | `Synced()` false | **hard deny** (unknown closure is never softened) |
| `stale` | freshness seam returns error (`state.StalenessError` or any error) | **hard deny** |
| `escape` | `Safe` Block with `len(Escaping) > 0` | downgraded to Warn by `Mode.Apply` → `allowed:true` + warnings |
| `invalid` | nil request / empty kind / unknown operation / unparsable payload / Project error | **hard deny** |
| `internal` | panic, encode failure, deadline exceeded | **hard deny** |

`Safe`'s own fail-closed deny (unresolvable target → Block with empty Escaping) passes
through as `escape`-code with `Safe`'s Reason and is likewise never softened —
`scope.Mode.Apply` (scope/scope.go:141) already guarantees `len(Escaping)==0` Blocks
survive audit; the webhook adds no second mode logic.

### `AdmissionResponse`
- `uid` — always echoes `request.uid` (even for fail-closed and malformed paths where a uid exists).
- `allowed` — `dec.Verdict != closure.Block` after `Mode.Apply`.
- `result.message` — the reason string (code + `dec.Reason` + provenance + escaping refs by `Ref.String()`); `result.reason` = `"KRSMDenied"`.
- `warnings` — on Warn (audit downgrade or `closure.Warn`/External): provenance + escaping/external refs.
- `patch`/`patchType` — **never set** (validating).
- Nothing from `rest.Config`, tokens, or object `data` ever appears in message/warnings/logs (Secrets are metadata-only in cache; reasons name refs, not contents).

### Staleness protocol (bounded, per plan risk #1)
1. `dec₁ = closure.Safe(state, action, clauses)`.
2. `targetRV = request.oldObject.metadata.resourceVersion`; **absent/empty → deny(stale)**
   (admission/v1 populates oldObject for DELETE/UPDATE; an absent RV means we cannot
   confirm currency — fail closed, documented).
3. `fresh.CheckFreshness(ctx, target, targetRV, dec₁.Closure)`; error → deny(stale).
4. `dec₂ = closure.Safe(...)` recomputed once — CheckFreshness may have reconciled the
   cache, changing the closure. `dec₂` is served. No second freshness pass: the residual
   (a member changing between step 3 and 4) is the documented ADR-0004 window, identical
   to the slice-4 analysis.

## Behavior — request lifecycle (`Handle`)
1. Nil `request` / empty `kind`+`resource` → deny(`invalid`).
2. `!matcher.Matches(req)` → **admit** (allowed, no warnings — KRSM gates agents only).
3. CREATE (except pods/eviction) → **admit**.
4. `actionFromRequest` error → deny(`invalid`).
5. `!Synced()` → deny(`not-ready`).
6. Scope: `scope.Derive(action.Target)` (Level 0; slice 6 replaces this call with
   `resolveScope`). Provenance string = `string(pred.Provenance)`.
7. Steps 1–4 of the staleness protocol above.
8. `dec = mode.Apply(dec₂)`; build response.

`ServeHTTP` additionally: method/content-type gate → 405/415 (before any review
exists); decode failure with a recoverable `request.uid` → 200 + deny(`invalid`);
without a uid → 400 (nothing to address a response to); panic → 200 + deny(`internal`);
deadline → deny(`stale` if in freshness, else `internal`).

## Components & responsibilities
- `webhook/server.go` — `Server`, `Config`, `New`, `Handle`, response/reason builders.
- `webhook/action.go` — `actionFromRequest`, payload projection, sub-resource + eviction mapping.
- `webhook/matcher.go` — `AgentMatcher`, `AnnotationMatcher`.
- `webhook/freshness.go` — the `freshness` seam (doc-comment cross-ref to `state.Provider`).
- `webhook/http.go` — `ServeHTTP`, `NewMux`, deadline, recover, certReloader.
- `state/provider.go` — `Scope()` accessor only.
- `cmd/krsm/main.go` — `serve` dispatch + `runServe` + flags (check path untouched).
- `internal/archguard` — unchanged; proves `webhook/` (client-go, k8s.io/api) leaks nothing into `closure`/`scope`.
- `go.mod` — `k8s.io/api` → direct (the `admission/v1` import realises it).
- Review debt (plan step 6): `internal/cluster/discover_test.go`; `state.New` wiring test; `PodsMatching`/`SelectorsMatchingLabels` parity rows.

## Alternatives considered
- **controller-runtime webhook builder** — rejected (umbrella design; unused manager
  weight, larger govulncheck surface). Raw `net/http` + `admission/v1` decode is ~200
  lines we fully control.
- **Gate CREATE with adopted-children detection** — deferred (umbrella open Q7): a
  CREATE carrying a pre-set ownerReference to an existing tree is a rare escape vector;
  noted in the design, not gated. Eviction, by contrast, IS gated (common, cheap, a
  plain delete).
- **Second freshness pass after the recompute** — rejected: it turns the bounded guard
  into a loop; ADR-0004 chose a bounded window, and slice 4's analysis already owns it.
- **Admit on missing oldObject RV** — rejected: "cannot confirm currency" admitting by
  default inverts the gate's one rule. Deny, and let #28 verify real servers always
  populate it.
- **Separate plaintext listener for probes** — rejected: kubelet probes speak HTTPS
  (`scheme: HTTPS` skips verification); one listener, no plaintext anywhere.

## Trade-offs & risks
- **Recompute-once staleness** trades a residual (documented) window for boundedness.
- **Annotation matcher is spoofable** by anything that can set annotations — acceptable
  for v0.5 (matcher interface is the slice-6/SECURITY.md extension point; provenance is
  reported, issuer identity is the documented deferred threat).
- **Eviction mapping** widens slice scope slightly but closes a genuine bypass; the
  mapping is 10 lines and one test.
- **mtime-based cert reload** is best-effort (no fsnotify dep); a rotation is picked up
  on the next handshake after mtime change — adequate for cert-manager's ~30-day windows.

## Testability (numbered — input for design-check-tdd)
Hermetic throughout: crafted `AdmissionReview` values/JSON + fake `closure.State`
(reuse `closure.NewScanState` over literal objects) + a fake freshness seam.

**actionFromRequest:**
1. DELETE → `Verb: Delete`, target carries the request's real GVK+ns+name+uid.
2. `propagationPolicy: Orphan` → `Cascade:false`; Background/Foreground/absent → `true` (S4).
3. UPDATE → `Old`/`New` projected; a selector change reaches the old∪new match-set (one
   golden-style case through `Safe`).
4. `subResource: scale` UPDATE → `Verb: Scale` on the parent.
5. pods/eviction CREATE → `Verb: Delete` on the pod (bypass closed).
6. CONNECT / unknown operation → error.
7. Unparsable `object`/`oldObject` JSON, or Project failure → error.

**Handle taxonomy & modes:**
8. Escaping delete: enforce → `allowed:false`, message has `krsm:escape` + escaping refs;
   audit → `allowed:true` + warnings naming the same refs + provenance `derived:ownership-tree`.
9. In-scope delete (target leaf, no collateral) → allowed, both modes.
10. Non-agent request (matcher miss) → admitted untouched; `AnnotationMatcher{Key:""}` matches all.
11. CREATE (non-eviction) → admitted before any state access (works even unsynced).
12. `Synced()==false` → `allowed:false` with `krsm:not-ready` — in **both** modes.
13. Unresolvable target (absent from state) → Safe's fail-closed Block survives audit.
14. Freshness seam error → `krsm:stale` deny, both modes; seam success → recompute served
    (fake state whose second Safe differs proves dec₂ is used).
15. Missing `oldObject` resourceVersion → `krsm:stale` deny.
16. `request.uid` echoed on every path incl. denies; `patch` never set; no reason string
    contains a token/data value (craft a Secret-referencing review, assert).

**ServeHTTP / lifecycle:**
17. Non-POST → 405; wrong content-type → 415; garbage JSON with no uid → 400.
18. Handler panic (poisoned fake) → 200 + `krsm:internal` deny.
19. Deadline exceeded in freshness → deny, not a hang (fake seam blocking on ctx).
20. `/readyz` 503 before sync, 200 after; `/healthz` always 200.
21. certReloader serves the new cert after the file changes (two self-signed certs, mtime bump).

**serve wiring & review debt:**
22. `runServe` refuses to start without cert/key; invalid `--mode` → usage error.
23. `DiscoverTargets` direct test: fake discovery → one Target per preferred GVR, Secret/
    ConfigMap enumerated as ordinary targets, C1-tolerant on unrelated group failure.
24. `state.New`-path wiring test via the seam (full/meta split matches `metadataKinds`).
25. Parity rows: `PodsMatching` and `SelectorsMatchingLabels` called directly against the
    corpus vs `NewScanState` (PR #32 review finding 5).

## Open questions
None blocking. Settled here: eviction gated as delete; missing-RV denies; probes share
the TLS listener; recompute-once staleness. Slice 6 replaces the `scope.Derive` call
site with `resolveScope` — the call is deliberately isolated in one function for that.
