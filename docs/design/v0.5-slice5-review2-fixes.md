# Design: v0.5-slice5-review2-fixes
Status: approved · Date: 2026-07-13 · Slug: `v0.5-slice5-review2-fixes` · Plan: docs/plans/v0.5-slice5-review2-fixes.md

## Summary
Round-2 fix design for PR #36 (branch `23-webhook-server`). Four contract changes carry
almost all of it: (1) a **sub-resource gate table** replaces the scattered
`"eviction"`/`"scale"` literals and adds `ephemeralcontainers` as a gated,
payload-carrying Update on the parent pod; (2) the **AgentMatcher interface grows a
`NeedsPayload()` capability** enabling two-stage (payload-free-first) matching, with
`AnnotationMatcher{Key:""}` demoted from match-all to match-nothing and an explicit
`MatchAll` matcher + `--gate-all` flag; (3) the **Freshness seam returns
`(reconciled bool, err error)`** and becomes constructor-required (`NoFreshness`
sentinel for tests), so the closure is recomputed only when the guard actually changed
the cache; (4) a **sixth taxonomy code `untracked`** denies kinds the informers do not
track, group+Kind-matched so non-preferred API versions are not falsely denied. Plus
local fixes: SA-list trimming, TypeMeta echo, eviction `deleteOptions`,
`--request-timeout` validation, CertReloader hardening, the `webhook/` write-verb
guard, and the shared ref-join helper.

## Interfaces / contracts

### `webhook/action.go` — the sub-resource gate table (findings 1, 8 + eviction-literal nit)
```go
// subResourceGate describes how one gated sub-resource maps to an Action. The table
// is the SINGLE source of truth: Handle's CREATE-admit branch, the rv precheck, and
// actionFromRequest all consult it — the three sites that drifted in round 2.
type subResourceGate struct {
    verb       closure.Verb // Scale | Delete | Update
    viaCreate  bool         // arrives as a CREATE (eviction) — exempts it from the CREATE admit
    carriesRV  bool         // oldObject carries the parent's resourceVersion (false: eviction)
    hasPayload bool         // project object/oldObject into Action.Old/New (ephemeralcontainers)
}

var gatedSubResources = map[string]subResourceGate{
    "scale":               {verb: closure.Scale, carriesRV: true},
    "eviction":            {verb: closure.Delete, viaCreate: true},
    "ephemeralcontainers": {verb: closure.Update, carriesRV: true, hasPayload: true},
}

func gatedSubResource(sub string) (subResourceGate, bool) // replaces the bool-only form
```
- **ephemeralcontainers**: the sub-resource carries **full Pod objects** in
  `object`/`oldObject`, so projection and the rv precheck work verbatim; the Action is
  `Verb: Update` on the parent pod (target GVK via `KindFor`, uid from `oldObject`).
  Verdict value under Level-0 = closure members outside the pod-rooted tree: the walk's
  unconditional rule 7 (`closure/closure.go:81`) pulls the pod's binding
  Service/PDB/NetworkPolicy into the closure, so injecting a debug container into a
  routing-bound pod is flagged (the target itself is trivially inside its own derived
  tree); slice-6 re-rooted scopes widen this to genuine out-of-scope pods. Plus all
  fail-closed paths (stale/untracked/unsynced) now cover the injection vector.
  *Documented model boundary:* an in-scope pod gaining an `envFrom` ref to an out-of-scope Secret stays
  Allowed — `closure/classify.go` treats forward references as reads, not effects
  (thesis-backlog issue, not a webhook fix).
- **eviction cascade (finding 8)**: `Cascade` is read from the decoded Eviction body's
  `deleteOptions.propagationPolicy` (`newU`; `req.Options` holds CreateOptions for the
  eviction CREATE, so the existing `cascadeFromOptions` never sees it). Orphan → false;
  absent/undecodable → true (conservative). Target stays UID-less (no oldObject exists).

### `webhook/matcher.go` — two-stage matching (findings 3, 5 + SA trim)
```go
// AgentMatcher gains a capability method (breaking, pre-release, no external impls):
type AgentMatcher interface {
    // Matches must answer conservatively when payloads are nil (stage 1):
    // false-with-nil-payloads means "cannot tell from the request alone".
    Matches(req *admissionv1.AdmissionRequest, object, oldObject *unstructured.Unstructured) bool
    // NeedsPayload reports whether a nil-payload miss is inconclusive and stage 2
    // (decode + re-match) is required.
    NeedsPayload() bool
}

// MatchAll gates every request — the explicit spelling of what AnnotationMatcher{""}
// used to mean. Config.Matcher nil still defaults to MatchAll (library-conservative).
type MatchAll struct{}                       // Matches: true, NeedsPayload: false

// AnnotationMatcher SEMANTICS CHANGE: Key "" now matches NOTHING (a disabled matcher),
// not everything. NeedsPayload = Key != "".
// ServiceAccountMatcher: NeedsPayload = false (identity is on the request).
// AnyMatcher: Matches = OR; NeedsPayload = OR over children.
```
`NewServiceAccountMatcher` (and the cmd flag parsing) trims each entry
(`strings.TrimSpace`) and drops empties — `"a, b"` yields two live identities.

### `webhook/server.go` — Handle lifecycle (new gate order)
1. Nil request / empty kind → deny(`invalid`).
2. CREATE where `!(gate.viaCreate)` for its sub-resource → **admit** (payload-free).
3. Ungated sub-resource on non-CONNECT → **admit** (payload-free).
4. **Stage-1 match** `matcher.Matches(req, nil, nil)`:
   - hit → agent; decode payloads; decode failure → deny(`invalid`) (an agent payload
     the gate cannot read is an unknown closure).
   - miss and `!NeedsPayload()` → **admit** (payload-free — the hot non-agent path).
   - miss and `NeedsPayload()` → decode; **decode failure → admit** (an undecodable
     payload cannot carry the annotation — restores round-1 channel semantics; only
     identity-matched agents fail closed on decode); else **stage-2 match**; miss →
     admit.
5. Agent CONNECT → deny(`invalid`) (unchanged).
6. `actionFromRequest` (table-driven) error → deny(`invalid`).
7. `!synced()` → deny(`not-ready`).
8. **Untracked precheck (finding 4):** `!s.info.Tracked(action.Target.GVK)` →
   deny(`untracked`) — both modes, fail-closed stands, but the code is distinct from
   `not-ready` (transient) and `escape` (computed). Runs after the sync gate so a
   syncing cache never reports `untracked`.
9. rv precheck iff `gate.carriesRV` (table-driven; replaces the `!= "eviction"`
   literal) and `s.fresh != NoFreshness`.
10. `scope.Derive` → `closure.Safe` → freshness guard: recompute **only if
    `reconciled`** (finding 9).
11. `ctx.Err()` → deny(`internal`); `Mode.Apply`; respond.

Taxonomy: `reasonUntracked reasonCode = "untracked"` — sixth code, message names the
GVK and the remedy ("kind is not tracked by the informer set; see docs — a correct
install generates webhook rules from the tracked set").

`respond` (finding 6): echoes `review.TypeMeta` when both APIVersion and Kind are
non-empty; stamps admission/v1 otherwise. Slice 7 additionally pins
`admissionReviewVersions: ["v1"]` (deferred issue).

`decisionResponse`: early-return on `closure.Allow` before message building; Block/Warn
grammar unchanged. `refsSuffix` and cmd `joinRefs` both delegate to a new stdlib-only
`closure.JoinRefs(refs []closure.Ref) string` (", "-joined `Ref.String()`s, beside
`Ref.String` — archguard-safe).

Three-admit repetition → one `admit(review)` helper beside `deny`.

### `webhook/freshness.go` + `state/provider.go` (finding 9 + Fresh nit)
```go
type Freshness interface {
    // reconciled reports whether the guard changed the cache (any upsert), i.e.
    // whether a recompute can observe anything new. (false, nil) = cache was already
    // current — the steady-state fast path; caller serves dec₁ without a second walk.
    CheckFreshness(ctx context.Context, target closure.Ref, targetRV string,
        neighbourhood []closure.Ref) (reconciled bool, err error)
}

// NoFreshness is the explicit "no staleness guard" sentinel (hermetic tests; the CLI
// one-shot path). New REJECTS a nil Fresh — disabling the C2 guard must be spelled
// out, never defaulted (constructor altitude, like State/Synced/Mode).
var NoFreshness Freshness = noFreshness{}
```
`state.Provider.CheckFreshness` adopts the new signature: fast path `(false, nil)`;
reconcile loop returns `(upsertsHappened, nil)` or `(_, *StalenessError)`. Callers:
webhook seam + provider tests + parity tests (mechanical).

### `state/provider.go` — lookups (finding 4 support + KindFor nit)
```go
// Tracked reports whether the informer set tracks the resource, matching by
// group+Kind (version-insensitive): informers watch preferred versions, but a request
// may arrive via any served version — an exact-GVK test would falsely deny those.
func (p *Provider) Tracked(gvk closure.GVK) bool
// KindFor becomes O(1) over a map[schema.GroupResource]closure.GVK built once in New.
```
`webhook.clusterInfo` gains `Tracked(closure.GVK) bool`.

### `cmd/krsm serve` (findings 2, 3, 7 + default-duplication nit)
```
--agent-annotation KEY     "" now DISABLES annotation matching (was: match-all)
--agent-serviceaccount LIST  comma-separated, entries trimmed, empties dropped
--gate-all                 explicit match-everything (the old "" behaviour)
--request-timeout D        default webhook.DefaultRequestTimeout (exported, 10s);
                           reject D <= 0 or D >= 30s (the API-server timeoutSeconds
                           ceiling — a longer verdict can never be delivered)
```
`agentMatcher(annotation, serviceAccounts string, gateAll bool)`:
`gateAll` → `MatchAll{}`; else compose the non-empty signals into `AnyMatcher`;
**no signal → fail-fast usage error** ("configure --agent-annotation,
--agent-serviceaccount, or --gate-all"). Server Read/WriteTimeout stay 30s/30s
(consistent with the <30s request-timeout bound); no derivation needed.

### `webhook/tls.go` — CertReloader (nits)
`GetCertificate` fast path is lock-free: `atomic.Pointer[tls.Certificate]`; an mtime
probe runs at most once per `probeInterval` (10s) and stats **both** cert and key
files; reload (under a mutex, off the common path) swaps the pointer only on a
successful `LoadX509KeyPair`. Contract unchanged: initial load fails fast; a
half-written rotation keeps serving the previous pair.

### `webhook/` write-verb source guard (finding 10)
`webhook/sourceguard_test.go` mirrors `state/informer_test.go:63-81`: scan the
package's non-test sources for client-go write verbs (`Create|Update|Patch|Delete|
Apply` call patterns on clients); the umbrella design §Security names both packages.

## Data model
- `gatedSubResources` table (above) — the one new internal shape.
- `reasonCode` gains `untracked`; the reason-string grammar (`krsm:<code>: <detail>`)
  is unchanged, so slice-8 e2e greps keep working.
- No wire-format, CRD, or golden-corpus changes. `closure/` gains only the pure
  `JoinRefs` helper (stdlib-only; archguard unaffected).

## Behavior — decision changes vs today
| Request | Today | After |
|---|---|---|
| Agent UPDATE `pods/ephemeralcontainers`, pod out of derived scope | admitted payload-free | audit Warn / enforce Block (target inclusion) |
| `--agent-serviceaccount "a, b"`, request by b | silently ungated | gated |
| `--agent-serviceaccount X --agent-annotation ""` | gates ALL traffic | gates X only |
| No gating flags, no `--gate-all` | gates everything silently | serve refuses to start |
| Non-agent UPDATE, payload undecodable | deny(`invalid`) | admitted |
| Non-agent DELETE/UPDATE (identity matchers only) | 2 payload decodes | zero decodes |
| Agent DELETE of an untracked-kind object | deny(`escape`, empty set), both modes | deny(`untracked`), both modes, remedy in message |
| Eviction with `propagationPolicy: Orphan` | Cascade:true closure | Cascade:false closure |
| v1beta1 AdmissionReview | response claims v1 | response echoes v1beta1 |
| Steady-state gated request (cache in sync) | 2× closure walk | 1× closure walk |
| `--request-timeout 45s` | accepted, conn killed mid-verdict | rejected at startup |

Unchanged invariants: fail-closed taxonomy semantics for the five existing codes; uid
echo on every path; no patch; credential-free reasons; audit never softens
empty-Escaping Blocks; `closure`/`scope` stdlib-only.

## Alternatives considered
- **Split matcher interfaces (RequestMatcher/PayloadMatcher)** — rejected: two types +
  composition rules for what one capability bit expresses; `NeedsPayload()` keeps
  `AnyMatcher` trivial.
- **Tri-state `Matches` return** — rejected: every implementor must reason about three
  outcomes; the two-call protocol keeps each matcher a plain predicate.
- **Keep `""`=match-all + a `none` sentinel** — rejected at plan review: the zero value
  occupying the "off" position is the root cause of finding 3; pre-release is the only
  cheap time to fix it.
- **Soften `untracked` to an audit Warn** — rejected (plan review): DESIGN §5's
  fail-closed rule is the product's one rule; adoption is protected by making the state
  unreachable (slice-7 rules from the tracked set) instead of by softening it.
- **Derive server timeouts from `--request-timeout`** — rejected: the API server's 30s
  `timeoutSeconds` ceiling makes longer verdicts undeliverable anyway; rejecting ≥30s
  is simpler and honest.
- **Exact-GVK `Tracked` test** — rejected: informers watch preferred versions; a
  served-but-not-preferred version request would be falsely denied `untracked`.
- **`fsnotify` for cert reload** — still rejected (round-1 decision stands); the
  atomic-pointer + rate-limited stat keeps the no-dependency property while fixing the
  lock-across-I/O nit.

## Trade-offs & risks
- **Interface breaks** (AgentMatcher, Freshness) are deliberate pre-release breaks;
  all implementors are in-repo. Custom-matcher authors later get a documented
  two-stage contract.
- **Stage-2 decode-failure admit** narrows fail-closed for the annotation channel to
  exactly its round-1 semantics; identity-matched agents still fail closed. The
  asymmetry is documented on the interface.
- **`untracked` before `Safe`** adds one O(1) map probe to every gated request; in
  exchange the `escape`-coded empty-Escaping Block now genuinely means "tracked but
  absent" (missing object), sharpening the taxonomy.
- **Recompute-on-reconciled** trusts the Provider to report upserts honestly; a false
  `false` would serve dec₁ over a changed cache. The Provider's contract test pins
  "any upsert → reconciled=true".

   admitted by the CREATE branch; every entry without `carriesRV` skips the rv
   precheck; table-driven over the table itself.
4. Eviction with Orphan `deleteOptions` in the body → `Cascade:false` action;
   Background/absent/garbage → true.

6. `AnnotationMatcher{Key:""}` matches nothing; `MatchAll{}` matches everything;
   `AnyMatcher` NeedsPayload composition.

   deny(`invalid`).
