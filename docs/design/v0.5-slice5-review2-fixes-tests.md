# Test list: v0.5-slice5-review2-fixes  (source: docs/design/v0.5-slice5-review2-fixes.md)
Ordered as vertical slices — implement one before writing the next. Hermetic throughout
(crafted AdmissionReviews + `closure.NewScanState` fakes + seam fakes); `make check` is
the closing gate.

1. [ ] An agent UPDATE to `pods/ephemeralcontainers` on an out-of-scope pod is flagged
       (audit → allowed + warning naming the pod; enforce → `krsm:escape` deny); an
       in-scope pod is allowed. (Drives the gate-table entry + Update-on-parent mapping.)
2. [ ] An ephemeralcontainers UPDATE whose oldObject carries no resourceVersion is
       denied `krsm:stale` (the rv precheck applies — `carriesRV`).
3. [ ] Gate-table drift guard: for every `gatedSubResources` entry, a `viaCreate` entry
       is NOT admitted by the CREATE branch and a `!carriesRV` entry skips the rv
       precheck — asserted table-driven over the table itself (kills the three
       `"eviction"` literals).
4. [ ] An eviction whose Eviction body carries `deleteOptions.propagationPolicy: Orphan`
       yields `Cascade:false`; Background/Foreground/absent/garbage yield `true`.
5. [ ] `--agent-serviceaccount "a, b"` gates requests from both `a` and `b`; empty and
       whitespace-only entries are dropped.
6. [ ] `AnnotationMatcher{Key:""}` matches nothing; `MatchAll{}` matches everything;
       `AnyMatcher.NeedsPayload()` is the OR of its children; `ServiceAccountMatcher`
       and `MatchAll` report `NeedsPayload() == false`.
7. [ ] Two-stage matching: with an identity-only matcher a non-agent DELETE/UPDATE is
       admitted with ZERO payload decodes (poisoned-payload review proves no decode);
       with an annotation matcher an undecodable payload is ADMITTED (cannot carry the
       annotation); an SA-matched agent with an undecodable payload is denied
       `krsm:invalid`.
8. [ ] Under the new gate order an agent CONNECT is still denied `krsm:invalid` and a
       non-agent CONNECT is admitted (stage-1 miss, payload-free).
9. [ ] An agent action on an untracked GVK is denied `krsm:untracked` in BOTH modes; a
       tracked-but-absent object still denies `krsm:escape`; an unsynced cache reports
       `krsm:not-ready` (sync gate wins); a tracked kind addressed via a non-preferred
       served version is NOT denied untracked (group+Kind match).
10. [ ] Freshness seam returns `(reconciled, err)`: fast path (false, nil) serves dec₁
        with exactly ONE closure walk (Safe call count); (true, nil) triggers exactly
        one recompute; any error denies `krsm:stale`. Provider side: in-sync fast path
        reports reconciled=false; a reconciling upsert reports reconciled=true
        (contract test pinning "any upsert → true").
11. [ ] `webhook.New` rejects a nil Fresh; `NoFreshness` skips the rv precheck and the
        guard; `buildWebhookConfig` still pins `Fresh: provider` (existing test
        updated to the new constructor contract).
12. [ ] `respond` echoes a v1beta1 request review's TypeMeta on the response; a review
        with empty TypeMeta gets admission/v1 stamped.
13. [ ] serve flag validation: `--request-timeout` ≤ 0 or ≥ 30s is a usage error; the
        flag default equals exported `webhook.DefaultRequestTimeout`; no gating signal
        (no annotation, no SA, no `--gate-all`) is a usage error; `--gate-all` wires
        `MatchAll`.
14. [ ] `closure.JoinRefs` renders ", "-joined `Ref.String()`s; `refsSuffix` and cmd
        `joinRefs` delegate to it with byte-identical output for existing cases.
15. [ ] CertReloader: a rotation rewriting BOTH files is picked up after the probe
        interval; a key-only rewrite is picked up (both files stat'd); concurrent
        `GetCertificate` is race-free under `-race`; a half-written pair keeps serving
        the previous cert.
16. [ ] `webhook/` write-verb source guard: no non-test source in the package invokes a
        mutating client verb (pattern mirrored from `state/informer_test.go`).
17. [ ] Closing gate: full corpus goldens 01–27 unchanged; `make check` green (gofmt,
        vet, golangci-lint, staticcheck, `go test -race`, archguard).
