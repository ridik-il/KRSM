# Plan: v0.5-slice5-webhook-server
Status: approved · Date: 2026-07-11 · Slug: `v0.5-slice5-webhook-server`

## Problem
Slices 1–4 delivered the whole state path — hardened reads, shared projection, the
informer-backed indexed `state.Provider`, and the per-request staleness guard — but
**nothing serves a verdict before an action persists**. The product surface of v0.5
(ROADMAP §v0.5, ADR-0011) is the audit-first `ValidatingWebhook`, and today there is no
`webhook/` package, no `serve` subcommand, and no `admission/v1` import anywhere in the
repo. Issue: [#23](https://github.com/ridik-il/KRSM/issues/23). Umbrella docs:
`docs/plans/v0.5-admission-webhook.md` §Steps(5), `docs/design/v0.5-admission-webhook.md`
§"`webhook/`".

This slice also closes the request-fidelity gaps only the webhook can close:
- **#16 / S2 (webhook half):** the `AdmissionRequest` carries the real GVK + uid — no
  discovery-guess target resolution (the CLI half, incl. the core-group qualifier, is done).
- **#18 / S4:** `DeleteOptions.propagationPolicy` from `request.options` maps
  Orphan→`Cascade:false` (the CLI hardcodes cascade true; `grep propagationPolicy` = 0 hits
  today).
- **#15 / S1 (webhook half):** per-request deadline ≤ the webhook config's
  `timeoutSeconds`, fail-closed on timeout (the CLI `--timeout` half is done).

## Goals / Non-goals
- Goal: `webhook/` package — `Server`, `Handle` (pure over an `AdmissionReview`),
  `ServeHTTP` (TLS, deadline, panic-recovery), `actionFromRequest`.
- Goal: the full **fail-closed taxonomy** of the umbrella design §Behavior, each with a
  distinct, credential-free reason: not-synced / staleness-drift / unresolvable target /
  decode-invalid / internal-error-timeout-panic.
- Goal: verdicts via the **unchanged** shared decision procedure:
  `closure.Safe` → `scope.Mode.Apply` (`scope/scope.go:141`), Level-0 derived scope only
  (`scope.Derive`, `scope/scope.go:114`).
- Goal: staleness-guard integration — `Provider.CheckFreshness` with the request object's
  `resourceVersion` and the computed closure neighbourhood (`state/provider.go:373`).
- Goal: `cmd/krsm serve` subcommand — flags for mode/TLS cert+key/listen addr/agent
  matcher; builds `state.New` → `Start` → `WaitForCacheSync`; `/readyz` gated on
  `HasSynced` (slice 7's probe target), `/healthz` liveness.
- Goal: promote `k8s.io/api` from indirect (`go.mod:42`) to direct (the `admission/v1`
  import makes it real).
- Goal (carried review debt from PR #32): direct tests for `cluster.DiscoverTargets` +
  `state.New` production wiring; `PodsMatching`/`SelectorsMatchingLabels` exercised
  directly in the parity table.
- Non-goal: Level 1/3 scope resolution (`krsm.io/target` annotation, TaskContract
  informer), the cross-boundary allowlist, provenance beyond `derived:ownership-tree` —
  **slice 6 (#24)**. `resolveScope` here is the minimal Level-0 seam slice 6 extends.
- Non-goal: deployment artifacts — `ValidatingWebhookConfiguration`, RBAC extension,
  cert-manager/CA bootstrap, Helm chart — **slice 7 (#25)**. This slice takes cert/key
  file paths and reloads on change; issuing them is slice 7's job.
- Non-goal: kind e2e (**#27**) and the real-cluster test (**#28**). This slice is
  hermetic-only (crafted `AdmissionReview` JSON + fake state), per the milestone's
  testing split (#26).
- Non-goal: any change to `closure/`, `scope/`, or the golden corpus (archguard-enforced).

## Approach
Raw `net/http` + `k8s.io/api/admission/v1` decode — no controller-runtime (umbrella
design "Alternatives"; the manager surface is unused weight). The package split keeps
`Handle` **pure**: it takes a decoded `AdmissionReview` plus its collaborators
(`closure.State`, a `freshness` interface seam over `Provider.CheckFreshness`, the mode,
the agent matcher) and returns an `AdmissionReview` — every fail-closed branch is
table-testable without a socket. `ServeHTTP` owns the impure edge: strict JSON decode,
per-request `context.WithTimeout`, panic-recovery to a fail-closed deny, response
encoding. `cmd/krsm serve` owns process wiring: flags, `state.New`, sync gate, TLS
listener with cert reload (`GetCertificate` re-reading on file change — slice 7 rotates
certs), signal-driven shutdown reusing the S1 idiom from `runCheckLive`.

Request lifecycle per the umbrella design §Behavior, in order: decode-strict → agent
match (non-agent → admit) → CREATE → admit → `actionFromRequest` → sync gate →
`resolveScope` (Level 0) → `closure.Safe` → staleness guard over the decision's
closure refs → `Mode.Apply` → response (uid echoed, no patch, warnings carry
escaping refs + provenance, never data/credentials).

## Steps (vertical slices)
1. [ ] **`actionFromRequest` + strict decode** — `webhook/action.go`: operation→`Verb`
   (CREATE short-circuits admit upstream; CONNECT/unknown → fail-closed), real
   GVK+ns+name+uid target, `propagationPolicy`→`Cascade` (S4), `oldObject`/`object`
   projected via `cluster.Project` into `Action.Old/New`. Malformed → error (deny).
   Demoable: unit tests over crafted `AdmissionRequest` JSON.
2. [ ] **`Handle` + fail-closed taxonomy + mode split** — `webhook/server.go`: the
   lifecycle above minus staleness; the response builder; the five distinct deny
   reasons; audit vs enforce over a fake `closure.State` (escaping delete →
   `allowed:false` enforce / `allowed:true`+warning audit; in-scope admitted; non-agent
   admitted; CREATE admitted; uid echoed; no patch).
3. [ ] **Staleness-guard wiring** — `Handle` calls the freshness seam with the request
   object's `resourceVersion` and the decision's closure refs; unresolved drift →
   distinct deny in both modes. Hermetic via a fake freshness seam + the existing
   `state` fakes.
4. [ ] **`ServeHTTP` + TLS server + lifecycle** — deadline, panic recovery,
   `/readyz` (HasSynced) + `/healthz`; content-type and method strictness. Demoable:
   `httptest` over a real TLS listener.
5. [ ] **`cmd/krsm serve`** — flags (`--mode`, `--tls-cert`, `--tls-key`, `--listen`,
   `--agent-annotation`), Provider wiring, sync gate before serving, graceful shutdown.
   Demoable: subcommand test with a fake provider seam (pattern: `withFakeLiveReader`).
6. [ ] **PR #32 review debt** — `internal/cluster/discover_test.go` (fake discovery →
   one Target per preferred GVR, C1 tolerance); a `state.New` wiring test via the seam;
   `PodsMatching` + `SelectorsMatchingLabels` rows added to
   `state/parity_test.go:TestProviderMethodsMatchScanState`.

## Risks & unknowns
- **Staleness neighbourhood source**: the guard needs the closure refs *before* the
  final verdict; computing `Safe` once, then re-checking freshness of `dec.Closure` is
  the drift-triggered design (umbrella open Q3) — if drift reconciles, recompute once.
  Risk: a recompute loop; bound it to one retry then fail closed.
- **What carries the target RV**: DELETE/UPDATE reviews carry `oldObject` (needs
  `ValidatingWebhookConfiguration` with `matchPolicy` defaults — confirm `oldObject` is
  always populated for DELETE on supported K8s versions; if absent, treat as drift →
  FreshGet path).
- **Agent-identity matcher shape**: annotation key vs label vs both; over-matching gates
  human traffic, under-matching lets agents bypass. Slice 5 ships the mechanism behind
  one flag; the default key is an open question below.
- **Sub-resource requests** (`request.subResource != ""`, e.g. `scale`, `status`): a
  `scale` subresource UPDATE is a real `ScaleEffect` action; `status` is noise. Decide
  the admit/gate split explicitly, don't let it fall through.
- **TLS cert reload**: slice 7 rotates certs; if slice 5 loads once at startup, rotation
  breaks admission (umbrella risk). `GetCertificate` with mtime-based reload is cheap
  insurance now.

## Definition of done
Issue #23's done-when, verbatim: hermetic `Handle` tests over crafted `AdmissionReview`
JSON + a fake state — escaping `delete` → `allowed:false` (enforce) /
`allowed:true`+warning (audit); CREATE admitted; non-agent request admitted; Orphan
`DeleteOptions` → no cascade; malformed/not-synced/panic → fail-closed deny; `uid`
echoed; no `patch`. Plus: staleness drift denies with its distinct reason; `krsm serve`
starts, refuses to serve verdicts before sync, and shuts down on SIGTERM; `k8s.io/api`
is a direct dep; archguard still proves `closure`/`scope` stdlib-only; the three
PR #32 review-debt tests exist and pass; `make check` green.

## Open questions
1. **Agent matcher default**: gate on an annotation (`krsm.io/task` present?) vs a label
   (`krsm.io/agent=true`)? Lean: annotation key, flag-overridable, matcher interface so
   slice 6 can extend to serviceaccount identity.
2. **Sub-resources**: gate `scale` (it is a `ScaleEffect`) and admit everything else
   (`status`, `token`, …)? Lean yes — mirrors `classify`'s effect classes.
3. **CONNECT / unknown operations**: fail closed (deny) or admit-with-warning? Lean deny
   — an operation we cannot classify is an unknown closure (DESIGN §5).
4. **Response reason grammar**: reuse the CLI's verdict text (`cmd/krsm/main.go:476`
   idiom) or a structured `code=…` prefix for slice-8 e2e greps? Lean: shared helper in
   `webhook/`, CLI untouched.
