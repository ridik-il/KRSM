# Plan: v0.5-slice5-review2-fixes
Status: approved · Date: 2026-07-13 · Slug: `v0.5-slice5-review2-fixes`

## Problem
PR #36 (slice 5, `webhook/` server, branch `23-webhook-server`) passed its round-1 fix
verification, but the round-2 re-review (2026-07-13, high-effort, 8 finder angles + 4
verifier groups) reported **10 new findings** (8 CONFIRMED, 2 PLAUSIBLE) plus verified
sub-cap nits. Three are the under/over-gating class this slice exists to prevent:

1. **`pods/ephemeralcontainers` blind spot (CONFIRMED, worst).** The only way to add an
   ephemeral container is that sub-resource, and it is admitted payload-free
   (`gatedSubResource` = scale|eviction only, `webhook/server.go:108`). An agent
   injecting a debug container into an out-of-scope pod is never evaluated.
   *Honesty note (from `closure/classify.go`):* gating it closes the
   **mutate-an-out-of-scope-pod** hole via target inclusion; the envFrom-a-shared-Secret
   aspect stays Allowed — forward references are reads, not effects, in the closure
   model (a documented model boundary, not a webhook bug).
2. **`--agent-serviceaccount` comma-split without trim (CONFIRMED).**
   `cmd/krsm/main.go:667` stores `" b"` from `"a, b"` verbatim → that agent is silently
   ungated (false ALLOW).
3. **Identity-only gating unreachable (CONFIRMED).** `agentMatcher` always ORs the
   annotation matcher in, and `--agent-annotation ""` means match-EVERYTHING — so the
   review record's own recommended production config (SA-only) cannot be expressed,
   and `"" + enforce` gates all cluster traffic.

Remaining findings: (4) untracked kind → hard deny in BOTH modes (`scope.go:145` never
softens empty-Escaping Blocks; C1 tolerance makes untracked kinds routine — undercuts
ADR-0011 audit-first); (5) payload decode before matcher (`server.go:119`) — non-agent
traffic pays two unmarshals and an undecodable payload denies non-agents (DESIGN §5);
(6) PLAUSIBLE `respond()` hardcodes admission/v1 TypeMeta instead of echoing the
request's (latent v1beta1 trap); (7) `--request-timeout` unvalidated vs the hardcoded
30s Read/WriteTimeout; (8) eviction ignores the Eviction body's DeleteOptions
(Orphan → wrong, larger closure in the verdict text); (9) unconditional `closure.Safe`
recompute after a no-reconcile freshness fast path (2× closure walk per gated request);
(10) missing write-verb source-guard test for `webhook/` (umbrella design §Security
promises it for `state`/`webhook`; only `state/` has one).

Sub-cap nits (verifier-confirmed): `"eviction"` literal at 3 dispatch sites
(`gatedSubResource` is the single source at only 1 of 3); `Config.Fresh` optional-by-nil
while `New` validates every other safety collaborator; `CertReloader` stats only the
cert file + holds its mutex across stat/reload on every handshake; `refsSuffix`
duplicates cmd `joinRefs`; the 10s default defined twice (`defaultRequestTimeout` vs
flag literal); `decisionResponse` builds the message on the Allow path; `KindFor`
linear-scans per gated request.

Review record to append: `docs/design/v0.5-slice5-webhook-server.md` (same pattern as
round 1). Findings are also logged in the project memory (v0.5 milestone entity).

## Approach
One fix round on the existing PR branch (no new slice branch — round-1 precedent),
run through **design-doc → design-check-tdd → tdd**: the fix-round design lives in
`docs/design/v0.5-slice5-review2-fixes.md` (interface deltas); the slice-5 design doc
gets the round-2 **review record** section (round-1 pattern); derive the test list,
then red-green per step below. Go implementation
follows go-pro conventions inline in the main session (sub-agents cannot write files in
this environment); `make check` gates the round; the user commits and pushes.

Two decisions are taken as leans and confirmed at plan review (see Open questions):
matcher flag semantics (lean: `""` disables annotation matching; explicit `--gate-all`
opt-in for match-everything; serve fails fast when no gating signal is configured —
pre-release, so no compat debt) and the untracked-kind taxonomy (lean: new
`untracked` reason code, still a hard deny in both modes; slice 7 generates rules from
the tracked set so the state is unreachable in a correct install).

## Steps (vertical slices)
1. [ ] **Gate `pods/ephemeralcontainers` (F1).** Add to `gatedSubResource`; map in
   `actionFromRequest` as `Verb: Update` on the parent pod **with projected payloads**
   (the sub-resource carries full Pod objects, so projection and the rv precheck work
   verbatim — unlike the payload-less scale path). Tests: agent adds an ephemeral
   container to an out-of-scope pod → flagged (audit warn / enforce deny); in-scope pod
   → allowed; docs note the read-vector model boundary. Demo: hermetic Handle test.
2. [ ] **Matcher hardening (F2+F3+F5).**
   a. Trim + reject-empty entries in the SA list; startup log of the parsed set (F2).
   b. Flag semantics per the lean above: `--agent-annotation ""` = annotation matching
      OFF; new `--gate-all` for explicit match-everything; serve fails fast if no
      signal; `webhook.Config` default (nil Matcher → gate everything) unchanged for
      library/e2e use (F3).
   c. Two-stage matching (F5): payload-free identity pass first (matcher sees req with
      nil payloads); only a payload-needing matcher (annotation) triggers decode; a
      decode failure then means "cannot carry the annotation" → non-agent → admit —
      restoring round-1 semantics — while an identity-matched agent with an
      undecodable payload still denies (`invalid`). Non-agent hot path becomes
      payload-free (also the efficiency win).
3. [ ] **Protocol fidelity (F6+F8).** `respond` echoes the request review's TypeMeta
   when non-empty (else v1). Eviction: read `deleteOptions` from the decoded Eviction
   body (`newU`) → `Cascade`; keep UID-less target (no oldObject exists). Tests pin
   both.
4. [ ] **Untracked-kind identity (F4).** Precheck before `Safe`: target GVK not in the
   tracked set → deny with the new `untracked` reason (both modes — fail-closed stands);
   distinct from `not-ready` (transient) and `escape` (computed). Doc the operator
   remedy + the slice-7 rules-from-tracked-set requirement in the design doc.
5. [ ] **Freshness seam (F9 + Fresh nit).** `CheckFreshness` returns
   `(reconciled bool, err error)`; Handle recomputes only when `reconciled`. `New`
   requires `Fresh`; add `webhook.NoFreshness` sentinel for hermetic tests
   (constructor altitude, matching State/Synced/Mode).
6. [ ] **Serve config validation (F7).** Fail fast when `--request-timeout` ≥ the
   server write deadline; derive Read/WriteTimeout as `max(30s, requestTimeout+5s)` or
   reject — pick in design. Export `webhook.DefaultRequestTimeout` and use it as the
   flag default (kills the duplicated 10s).
7. [ ] **Write-verb source guard for `webhook/` (F10).** Copy the
   `state/informer_test.go:63` pattern.
8. [ ] **Cleanup pass (same-line nits).** `subResourceEviction` const + gated-set
   predicates so the CREATE-admit and rv-precheck sites consult the single source;
   `admit(review)` helper; Allow early-return in `decisionResponse`; `KindFor` prebuilt
   `map[GroupResource]GVK`; `CertReloader` stats the key file too + rate-limits the
   probe (atomic pointer optional); shared ref-join helper (stdlib-only, can live in
   `closure` beside `Ref.String`) used by `refsSuffix` and cmd `joinRefs`.
9. [ ] **Docs + review record.** Round-2 section in the slice-5 design doc (same
   pattern as round 1); CHANGELOG note; deferred issues filed (see below).

Deferred (file as issues, not in this PR): slice 7 — pin `admissionReviewVersions:
["v1"]`, generate webhook rules from tracked GVRs (makes F4's state unreachable);
research/model — forward-reference (read/exfil) relation note for the thesis backlog.

## Risks & unknowns
- **Matcher flag semantics change** alters current CLI behavior (`""` was match-all).
  Pre-release, single-digit users; still called out at review (Open Q1).
- **Two-stage matching** re-introduces a per-matcher capability distinction — the
  design must keep the interface honest (no silent payload-nil surprises for custom
  matchers). Design-doc responsibility.
- **`CheckFreshness` signature change** ripples through state tests, parity tests, and
  the webhook fakes — mechanical but broad; TDD per seam.
- **`untracked` precheck** must not mask genuine `Safe` fail-closed paths (target
  tracked but absent from cache = still `escape`-coded Block) — test both.
- **Ephemeralcontainers rv precheck**: confirm the sub-resource UPDATE's `oldObject`
  carries the pod's resourceVersion on the supported K8s versions (expected: yes; the
  e2e (#27) re-verifies on kind).
